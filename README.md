# ZENTAKO Website

Professional landing page for ZENTAKO — Real Estate Prospecting & Appointment Setting.

## Deploy with GitHub Pages
1. Open the repository **Settings**.
2. Go to **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save. GitHub Pages will publish the site.

## Before launch
- Replace the placeholder `hello@zentako.com` with your actual business email.
- Confirm that any contact details, service claims, markets, and policies are accurate.
- Connect a custom domain after domain purchase.
- Review relevant calling, privacy, lead-data and Do Not Call requirements for each campaign jurisdiction.

No fabricated testimonials, statistics or guaranteed results are included.
